# 🛡️ SOC Analyst Lab Portfolio

This repository documents my progress in cybersecurity and network defense through hands-on SOC labs, simulations, and incident investigations.

### Objective
To develop foundational skills in log analysis, network forensics, and intrusion detection while learning to document professional investigations.

### Current Focus
- Building familiarity with SIEM and IDS tools
- Understanding TCP/IP and network behavior
- Investigating malicious network traffic (brute force, phishing, etc.)
- Writing reports aligned with SOC Tier 1 standards
